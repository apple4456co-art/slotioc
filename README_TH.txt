SHOPEE AFFILIATE AUTOPILOT — EXTRA COMM EDITION
================================================
โปรแกรม Windows สำหรับจัดการข้อมูลสินค้า Extra Comm, สร้างร่างคอนเทนต์,
จัดคิววิดีโอ Meta AI, เตรียมชุดโพสต์ และส่งต่องานระหว่าง PC กับ Android

สิ่งที่โปรแกรมทำได้
- ใช้ Python 3.10+ และ Tkinter (ไม่ต้องติดตั้งไลบรารีเสริม)
- เก็บสินค้า/คิวงานใน SQLite ในเครื่อง
- บังคับกรอกหลักฐาน Extra Comm, รายละเอียดค่าตอบแทน และ Affiliate Link
- ตรวจรูปแบบ Affiliate Link ว่าเป็น https://s.shopee.co.th/...
- นำเข้า/ส่งออก CSV และป้องกัน Affiliate Link ซ้ำ
- กำหนดจำนวนคิวต่อรอบได้ 1–1,000 งาน และสร้างซ้ำได้โดยไม่จำกัดจำนวนรวม พร้อมสลับรูปแบบคอนเทนต์
- สร้างร่างบทรีวิว แคปชัน Hashtag และ Prompt สำหรับ Meta AI
- เปิด Meta AI และคัดลอก Prompt จากหน้าโปรแกรม
- แนบวิดีโอที่ดาวน์โหลดจาก Meta AI และเก็บสำเนาไว้ใน media/
- สร้างชุดโพสต์ที่รวมวิดีโอและ post_text.txt ไว้ใน post_kits/
- บันทึก URL โพสต์และสถานะที่ผู้ใช้ยืนยัน
- สำรองฐานข้อมูลได้
- Mobile Hub: เปิดหน้าเว็บบน Android ผ่าน Wi-Fi วงเดียวกับ PC
- มือถือดูคิว/สินค้า คัดลอก Affiliate Link, บท, Caption, Hashtag และ Prompt
- มือถืออัปโหลดวิดีโอเข้า PC หรือดาวน์โหลดวิดีโอจาก PC ได้
- ยืนยันสถานะโพสต์จากมือถือหลังโพสต์จริง
- ใช้ PIN 8 หลักและ session token พร้อม CSRF protection
- มี TEST.bat สำหรับทดสอบแกนหลักของโปรแกรม

ติดตั้ง
1. Windows 10/11
2. ติดตั้ง Python 3.10 หรือใหม่กว่า จาก https://www.python.org/downloads/
3. ระหว่างติดตั้งเลือก Add Python to PATH
4. แตก ZIP ไว้ในโฟลเดอร์ที่เขียนไฟล์ได้ เช่น Documents\ShopeeAutoPilot
5. ดับเบิลคลิก START.bat
6. จะเปิดโปรแกรม PC และหน้าต่าง Mobile Hub แยกกัน

เชื่อม Android กับ PC
1. เชื่อมคอมพิวเตอร์และ Android เข้ากับ Wi-Fi เดียวกัน (Guest Wi-Fi หรือเครือข่ายที่แยก Client อาจใช้งานไม่ได้)
2. เปิด START.bat บน PC และอย่าปิดหน้าต่าง "Shopee Affiliate Mobile Hub"
3. อ่าน IP และ URL ที่แสดงในหน้าต่าง Mobile Hub เช่น http://192.168.1.20:8765
4. เปิด Chrome บน Android แล้วพิมพ์ URL ตาม IP จริงที่แสดงบนคอม
5. กรอก PIN 8 หลักที่แสดงในหน้าต่าง Mobile Hub ตอนเริ่มครั้งแรก
6. ในหน้า "คิวงาน" แตะ "เปิดงาน" เพื่อคัดลอกข้อความแต่ละส่วนหรือส่งวิดีโอจากมือถือเข้า PC
7. เมื่อ PC มีวิดีโอแล้ว มือถือสามารถดาวน์โหลดวิดีโอจากรายการงาน
8. เปิดแอป Shopee บน Android เลือกวิดีโอและเลือกสินค้าที่ตรงกับงาน จากนั้นโพสต์ด้วยตนเอง
9. กลับมาที่ Mobile Hub แล้วกด "ยืนยันว่าโพสต์แล้ว" หลังโพสต์สำเร็จจริง

หากมือถือเข้า URL ไม่ได้
- ตรวจว่า PC และมือถืออยู่ Wi-Fi เดียวกัน
- ตั้ง Network Profile ของ Windows เป็น Private สำหรับ Wi-Fi ที่เชื่อถือได้
- เมื่อ Windows Firewall ถาม ให้ Allow Python เฉพาะ Private networks เท่านั้น
- หากไม่มีหน้าต่างถาม ให้สร้าง Inbound Rule สำหรับ TCP port 8765 เฉพาะ Private profile
- ตรวจว่าไม่มีโปรแกรมอื่นใช้ port 8765; เปลี่ยนได้ด้วย environment variable SHOPEE_HUB_PORT
- ห้ามเปิด port นี้ออกอินเทอร์เน็ตหรือทำ port forwarding ที่เราเตอร์
- หาก Wi-Fi เปิด AP/client isolation อุปกรณ์จะติดต่อกันไม่ได้

ความปลอดภัยและการเก็บข้อมูล
- PIN 8 หลักแสดงเฉพาะตอนสร้าง Mobile Hub ครั้งแรก จากนั้นจะใช้ PIN เดิม
- PIN hash ถูกเก็บใน mobile_hub_config.json ไม่เก็บ PIN แบบข้อความ
- หากลืม PIN: ปิด Mobile Hub, สำรองไฟล์ mobile_hub_config.json ไว้ก่อน แล้วลบไฟล์ดังกล่าวเพื่อสร้าง PIN ใหม่เมื่อเปิดอีกครั้ง
- อย่าแชร์ PIN หรือ URL ให้คนนอกเครือข่าย
- ใช้เฉพาะ Wi-Fi ที่เชื่อถือได้; HTTP ใน LAN ไม่ใช่การเข้ารหัสแบบ HTTPS
- ปิดหน้าต่าง Mobile Hub เมื่อไม่ใช้งาน
- ฐานข้อมูลเดิม affiliate_autopilot.db และโฟลเดอร์ media/ ใช้ร่วมกันทั้ง PC และมือถือ อย่าลบหรือย้ายระหว่างทำงาน

วิธีใช้สินค้าและคิวงาน
1. เปิด Shopee Affiliate Dashboard: https://affiliate.shopee.co.th/dashboard
2. ตรวจสอบสินค้าในบัญชีจริง รวมถึง Extra Comm, อัตรา และช่วงเวลาที่มีผล
3. สร้าง Affiliate Link ผ่านเครื่องมือที่ Shopee ให้บัญชีคุณใช้
4. เพิ่มสินค้าในแท็บ "สินค้า Extra Comm" หรือใช้ CSV template
5. ใส่หลักฐาน Extra Comm, รายละเอียดค่าตอบแทน, วันที่ตรวจสอบ และ Affiliate Link
6. สร้างคิวจากสินค้าที่เลือกหรือสร้างคิวประจำวัน
7. เลือกงาน คัดลอก Prompt ไปใช้ที่ https://www.meta.ai/
8. สร้างและดาวน์โหลดวิดีโอจาก Meta AI ด้วยตนเอง
9. แนบวิดีโอใน PC หรืออัปโหลดจาก Android ผ่าน Mobile Hub
10. เตรียมชุดโพสต์และโพสต์ผ่านแอป Shopee ด้วยตนเอง
11. บันทึก URL โพสต์เพื่อเก็บประวัติ

ข้อจำกัดสำคัญ — อ่านก่อนใช้
- โปรแกรมนี้ไม่เชื่อม Shopee Open API
- โปรแกรมไม่ scrape หน้า Shopee, ไม่เก็บรหัสผ่าน Shopee และไม่ใช้ browser automation
- หลักฐาน Extra Comm เป็นข้อมูลที่ผู้ใช้บันทึก ไม่ใช่การตรวจสอบสถานะสดจาก Shopee
- ตรวจสอบ Extra Comm, อัตรา, ระยะเวลา, สต็อก, ราคา และสิทธิ์ของลิงก์ก่อนโพสต์ทุกครั้ง
- โปรแกรมไม่สามารถสั่ง Meta AI สร้างวิดีโอผ่าน API ที่ยืนยันว่าเปิดให้สมาชิกทั่วไปใช้ได้
- โปรแกรมไม่สามารถโพสต์ Shopee Video หรือแนบสินค้าแทนคุณได้โดยตรง
- Mobile Hub เป็นเว็บเซิร์ฟเวอร์ภายใน LAN ไม่ใช่ Cloud และมือถือจะใช้ได้เมื่อ PC เปิดอยู่
- การคัดลอก Clipboard ขึ้นกับสิทธิ์ของเบราว์เซอร์/HTTPS; หากถูกบล็อก ให้คัดลอกจากข้อความบนหน้าเว็บ
- ร่างบทและแคปชันเป็นข้อความจากข้อมูลที่ป้อน ไม่ใช่คำรับรองว่ามีการทดสอบ/ใช้สินค้าจริง
- ตรวจสอบข้อกล่าวอ้างและเปิดเผยความสัมพันธ์ Affiliate ตามกฎของแพลตฟอร์มก่อนเผยแพร่

ไฟล์ข้อมูล
- affiliate_autopilot.db       ฐานข้อมูลสินค้าและคิวงาน
- mobile_hub_config.json       ค่า PIN hash ของ Mobile Hub
- media/                       วิดีโอที่แนบ/อัปโหลด
- post_kits/                   ชุดโพสต์ที่เตรียมไว้
